# 面向考插的微积分讲义

### 4份讲义：

主要面向大一考复旦插班生的同学而写，本人25年考这个复旦插班生，25-26年又自己带了几个小灯，于是想凝练一下自己的学习成果，即使微不足道，但也一定会帮助到后来人。

因为本人考过知道怎么备考，考哪些，讲义基本说人话，含部分考过的真题讲解。但鉴于升入大二之后，无心刷微积分题目，也无心再带新一届的小灯，于是停更，并将此仓库开源

含四个专题，就是主目录的那几个pdf。写的最好的据小灯说是**Laplace方法**那一集，最详细的应该是**积分**那一集，学完常微分之后再看不太严谨的是**线性代数**那一集，期末周拼命肝出来的是**曲面积分**那一集

all in all, enjoy it!
